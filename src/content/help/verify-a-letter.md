Every letter has a code and a link to the **Verify** page. You don't need an account to use it.

## Check a letter

Open **Verify** (in the top bar when you are signed out) and type the letter code. Capital letters, spaces, and dashes don't matter. You can also follow the link or QR code printed on the letter.

## What the status means

- **Valid**: "This letter is current."
- **Superseded**: a newer letter was issued, or the hours on this letter changed after it was issued.
- **Revoked**: the letter was withdrawn. The page shows the reason, such as "issued in error".

Each status shows an icon and words, never color alone.

## What else the page shows

- The volunteer's display name (first name and last initial)
- Total verified hours, the date range, and the organizations
- The issue date and the letter code

## What this means

Hours on a letter come from shift check-ins or coordinator-approved records at verified organizations. An edited PDF will not match this page, so the page is the source of truth.

If the code isn't found, you'll see "We couldn't find a letter with that code. Check the code and try again."
