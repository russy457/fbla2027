A verified hours letter is a one-page PDF that lists your approved hours by organization. It has a letter code and a link so a school or employer can confirm it is real.

## Get your letter

1. Open **Impact** and press **Get verified letter**.
2. Check the preview. It shows hours per organization and, if any, "Hours excluded: N from unverified orgs".
3. Press **Issue letter**.
4. When it is ready, **Download PDF** or **Copy verify link**.

If creating the PDF fails, you'll see "We couldn't create the PDF." with a **Retry** button.

## What counts

- Only **approved** hours count. Pending and rejected hours do not.
- Only hours from **verified** organizations count. Hours from unverified organizations are listed as excluded.
- If you have no approved hours from verified organizations, the app tells you instead of making an empty letter.

## Getting a new letter

If you issue a new letter for the same scope, the older one is marked **superseded**, and its verify page points to the newer date. Letters are a snapshot: your PDF never changes after it is issued. If the hours behind it change, the verify page says so.
