An organization has one **owner** (the person who registered it) and any number of **coordinators**. Coordinators can run shifts, the kiosk, hours, attendance, and reports. Only the owner can edit the organization, invite people, and remove members.

## Invite a coordinator (owners)

1. Open your organization's **Settings**.
2. Under invites, press **Create invite**.
3. Copy the 10-character code and send it to the person yourself, for example in a text or in person.

Things to know:

- The code is **shown only once**. If you lose it, create a new one.
- Each code works for **one person** and expires after **7 days**.
- The app does not send the code for you.

## Join with a code

1. Sign in and finish setting up your profile.
2. Open [Join an organization](/join).
3. Enter the code and press join.

You become a coordinator, and the organization shows up in your org switcher. If the code is wrong, used, or older than 7 days, you'll see "This invite code is invalid or expired." Ask the owner for a new code. If you already belong, you'll see "You're already a member of this organization."

Coordinators under 18 can run shifts but never see volunteers' contact details.

## Remove a member (owners)

In **Settings**, find the person under members and press **Remove**. They lose access to the organization right away. The owner can't be removed.
