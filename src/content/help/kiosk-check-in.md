When you arrive, the organization has a tablet (the kiosk) showing a 6-digit code. Typing that code on your phone proves you are there.

## Check in

1. Open **My Shifts** and find today's shift.
2. Press **Check in**.
3. Type the 6-digit code shown on the kiosk right now and press **Submit**.
4. You'll see a message like "Checked in at 9:02, check-out opens 9:17".

## When check-in is open

Check-in opens **30 minutes before** the shift starts and stays open until the scheduled end. Before that, the button says when it opens.

You need a confirmed spot on the shift. If you didn't sign up, ask the coordinator.

## Why the code keeps changing

The code changes every **30 seconds**. The current code and the one just before it both work, so you have about a minute to type it. If it was rejected, type the code on the screen now.

## Scanning a QR code

The kiosk also shows a QR code. On the secure website, press **Scan QR** on the check-in screen and point your camera at it. Typing the code always works too, so if your camera is blocked or scanning fails, switch to typing the code.

## Please don't share codes

Someone at the kiosk could read a code to a friend who isn't there. Coordinators watch arrivals live and can correct attendance, and checking in for someone who isn't present breaks the trust that makes letters meaningful.
