Kiosk mode turns a tablet into the check-in station for one shift. A typical setup uses three devices: your laptop with the roster, the kiosk tablet, and each volunteer's phone.

## Start the kiosk

1. On the tablet, sign in and open the shift from your **Dashboard**.
2. Press **Start kiosk**. You can start it from **1 hour before** the shift until 30 minutes after it ends.
3. The tablet signs you out and runs as a kiosk for this shift only, so your account is not left open on a shared device.

## What the kiosk shows

- A large 6-digit code that changes every **30 seconds**, with a countdown ring
- The number of volunteers checked in and a live list of arrivals
- Codes from 30 minutes before the start until 30 minutes after the end

If the connection drops, the code dims and says "Reconnecting, codes paused". It never shows an old code as live.

Your laptop roster updates live too, so you can spot-check that each arrival is really there.

## Exit or restart

- **Exit kiosk** asks for a coordinator to sign in. Signing in ends the kiosk session.
- A kiosk session lasts up to 12 hours. If it expires, the tablet shows "Kiosk session expired, coordinator sign-in". Sign in and start the kiosk again.
- If the kiosk "isn't available for this shift right now", you are outside the start window above.
